# 🔥 FirebaseApp - Semana 1

Atividade desenvolvida para a disciplina **Desenvolvimento de Aplicativos II**.

## 📌 Objetivo da semana

Nesta primeira semana, o objetivo foi preparar o ambiente de desenvolvimento e criar o primeiro projeto Flutter utilizando o VS Code, substituindo o uso do Firebase Studio.

## ✅ O que foi realizado

- Instalação/verificação do Flutter
- Verificação do Dart
- Uso do VS Code como ambiente de desenvolvimento
- Criação do projeto Flutter chamado **FirebaseApp**
- Execução do aplicativo no navegador Google Chrome
- Criação do repositório no GitHub
- Publicação do projeto na branch **semana1**

## 🚀 Tecnologias utilizadas

- 🐦 Flutter
- 🎯 Dart
- 💻 Visual Studio Code
- 🌱 Git
- 🐙 GitHub
- 🌐 Google Chrome

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/Robson-ifes/FirebaseApp.git
```

Entre na pasta do projeto:

```bash
cd FirebaseApp
```

Troque para a branch da Semana 1:

```bash
git checkout semana1
```

Instale as dependências:

```bash
flutter pub get
```

Execute no navegador Chrome:

```bash
flutter run -d chrome
```

## 📁 Estrutura do projeto

O projeto foi criado com a estrutura padrão do Flutter:

```text
FirebaseApp/

  lib/

```

## 📝 Observações

Durante a configuração do ambiente, foi utilizado o Flutter localmente pelo VS Code, já que o Firebase Studio foi descontinuado pelo Google.

O aplicativo foi executado inicialmente na Web, utilizando o Google Chrome como dispositivo de teste.
